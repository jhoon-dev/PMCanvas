# 보안 점검 · 2026-10-27–28

이번 점검은 웹 0.21.0·데스크톱 0.2.0의 Excel 입출력과 관련 데이터·파일 경계를 중심으로 수행했습니다.

## 수정한 항목

- 웹 Excel 미리보기 이후 프로젝트가 바뀌면 이전 결과 적용을 차단합니다. 열린 가져오기 창에서도 백그라운드 조회가 편집 초안을 바꾸지 않도록 보호했습니다.
- 파일 재선택·설정 변경·늦은 오류 응답을 구분하고, 읽는 중에는 미리보기를 막아 이전 파일의 결과를 적용하지 않습니다.
- XLSX의 실제 압축 해제 크기·CRC·대소문자 중복 경로·매크로 MIME·외부 관계·내장 개체·DTD를 확인합니다. XML 문자 참조로 숨긴 External 속성도 파싱 후 검사합니다.
- 데스크톱의 파일 읽기는 열린 파일 디스크립터로 일반 파일 여부와 크기를 확인하고, 읽는 도중 커져도 제한을 넘는 데이터를 받지 않습니다.
- 설치 패키지의 앱 소스는 파일별 허용 목록으로 제한하고 ASAR 검사로 확인했습니다. 개발 의존성·임의의 생성 파일이 앱 파일 목록에 섞이지 않는지도 확인했습니다.
- 데스크톱 빌드 의존성 감사에서 발견한 12건을 electron-builder 26.18.0과 고정 잠금 파일 갱신으로 처리했습니다. 앱 실행 의존성과 빌드 의존성을 포함한 npm audit 결과는 0건입니다.

## 유지·검증한 경계

- 웹은 로그인·프로젝트 권한·CSRF·파일 작업 횟수·별도 프로세스의 시간/메모리 제한을 유지합니다.
- 데스크톱은 Node가 비활성화된 격리·샌드박스 렌더러, IPC 발신 프레임 검사와 네이티브 파일 선택을 유지합니다. 렌더러가 파일 경로를 지정하거나 직접 파일을 읽지 않습니다.
- Excel 적용은 원본 파일을 덮어쓰지 않고 문서를 미저장 상태로 바꿉니다. 미리보기 전후 revision 확인, 완료 기록·다중 세부 작업 보존, 복구 사본과 외부 변경 감지를 유지합니다.
- 외부 연결·암호화·수식이 있는 파일은 값으로 바꾼 XLSX를 사용해야 합니다. 전체 복원은 JSON/프로젝트 파일/DB 백업의 기존 범위를 유지합니다.

정식 배포용 Windows 코드 서명과 macOS 서명·공증은 인증서와 배포 환경 설정이 필요한 별도 운영 항목입니다. 이 PC의 검증 범위는 Windows 실행·패키징이며 macOS 실행 검증은 포함하지 않습니다.
