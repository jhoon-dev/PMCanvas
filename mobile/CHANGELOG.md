# 변경 이력

## 0.3.2

- Electron 기본 이미지를 PM Canvas 전용 P·일정 막대 아이콘으로 교체했습니다.
- 기존 데이터 저장 위치와 프로젝트 형식을 유지합니다.
- Google Play 내부 테스트에서 이미 사용한 코드를 피하도록 Android 버전 코드를 6으로 올렸습니다.

## 0.2.0

- 공통 진척 그래프, WBS 편집·계층·기준 계획·일정 점검을 제공합니다.
- 마일스톤·투입 계획·이슈·리스크·주간보고 화면과 Excel 입출력을 추가했습니다.
- 화면 이동 선택기와 인력·보고서 탭, 작은 글자 가독성을 개선했습니다.
- 빠른 업무 입력·완료 실행 취소·미저장 입력 보호와 작은 편집창을 유지합니다.
- 로그인·팀 공유·서버 기능은 웹에서 제공합니다.

## 0.1.0

- 기기 자동 저장, 업무·인력 편집, 완료 기록과 프로젝트·CSV 파일 공유를 제공하는 최초 모바일 버전입니다.
