# 변경 이력

## 1.10.2

- 아이콘의 바깥 박스를 제거하고 안쪽 캔버스와 P·일정 막대를 아이콘 전체에 표시합니다.

## 1.10.0

- 앱 설정의 AI 연결 화면에서 OpenAI API 키와 모델을 등록·변경·삭제하고 주간보고 금주·차주 설명 초안을 생성할 수 있습니다.
- 키는 운영체제 보안 저장소로 암호화하며, 생성은 초안 입력만 바꾸고 기존 미리보기·발행 절차와 프로젝트 파일 형식을 유지합니다.

## 1.9.2

- 빌드 도구의 picomatch 취약점을 수정하고 보안 검사를 보강했습니다.
- 기존 프로젝트·프로필·파일 형식을 유지합니다. MSIX **1.9.2.0**으로 배포합니다.

## 1.9.1

- Microsoft Store 반려 사유인 Electron 기본 아이콘을 PM Canvas 전용 P·일정 막대 아이콘으로 교체했습니다. 공유 아이콘 원본과 각 플랫폼의 파생 이미지도 통일했습니다.
- `unvirtualizedResources`와 파일 시스템 가상화 예외를 제거하고 `runFullTrust`만 유지합니다.
- Store 프로필을 `%USERPROFILE%\PM Canvas\Profile`에 보관하여 업데이트·제거·재설치 시 유지합니다. 기존 EXE 프로필은 최초 실행 때 원본을 보존하며 복사하고, 기존 Store 프로필을 덮어쓰지 않습니다.
- 앱 버전 1.9.1과 MSIX **1.9.1.0**으로 재제출합니다.

## 1.9.0

- 앱 표시 버전과 Microsoft Store 버전을 1.9.0으로 통일했습니다. 패키지는 예약 필드만 덧붙인 MSIX **1.9.0.0**이며 CI 빌드 번호로 버전을 바꾸지 않습니다.

- 여러 프로젝트 탭과 프로젝트·앱 설정 분리, 공통 관리 메뉴를 제공합니다.
- 웹과 공통인 진척 추이·타임라인·인력별 진척 그래프를 추가했습니다.
- 한국 공휴일 설정·달력 동기화·휴무일 선택과 계산 일관성을 개선했습니다.
- 작은 안내·메뉴·차트 글자를 최소 12px로 확대했습니다.
- 버전별 사용 매뉴얼과 현재 대규모 프로젝트의 실제 화면 캡처를 제공합니다.
