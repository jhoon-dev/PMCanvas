# 변경 이력

## 1.9.0

- 앱 표시 버전과 Microsoft Store 버전을 1.9.0으로 통일했습니다. 패키지는 예약 필드만 덧붙인 MSIX **1.9.0.0**이며 CI 빌드 번호로 버전을 바꾸지 않습니다.

- 여러 프로젝트 탭과 프로젝트·앱 설정 분리, 공통 관리 메뉴를 제공합니다.
- 웹과 공통인 진척 추이·타임라인·인력별 진척 그래프를 추가했습니다.
- 한국 공휴일 설정·달력 동기화·휴무일 선택과 계산 일관성을 개선했습니다.
- 작은 안내·메뉴·차트 글자를 최소 12px로 확대했습니다.
- 버전별 사용 매뉴얼과 현재 대규모 프로젝트의 실제 화면 캡처를 제공합니다.
