# 변경 이력

## 0.8.3

- Microsoft Store 배포용 개인정보처리방침을 공개하고 파일 옵션·네이티브 파일 메뉴에서 열 수 있게 했습니다.
- Excel 업무 현황의 WBS·세부 작업과 CSV에서 같은 계층 WBS 번호를 사용합니다. 상위·하위 업무의 배열 순서가 달라도 번호를 일치시킵니다.
- 네이티브 Excel 작업과 CSV 보고서의 계층 번호 회귀 검증을 추가했습니다.
- 기존 프로젝트 파일 형식과 완료 기록·계층·기준 계획·설정을 유지합니다.

## 0.8.2

- 업데이트 발행과 재공개는 `main`에서 빌드하고 현재 `main` 이력에 포함되는 커밋만 허용합니다.
- 같은 파일의 대소문자·경로 별칭·하드 링크로 저장해도 외부 수정 충돌을 검사합니다.
- 손상된 복구 파일은 별도 사본으로 보존한 뒤에만 교체하며, 보존 실패 시 원본을 유지합니다.
- 기존 프로젝트 파일 형식·완료 기록·이력·설정은 유지합니다.

## 0.7.4

- Windows 기본 배포를 Microsoft Store 제출용 MSIX로 전환했습니다. Partner Center 제품 ID 설정, SDK 검증·추출 비교·원본 커밋 검사와 CI 설치 검증을 추가했습니다.
- 기존 EXE에서 MSIX로 전환할 때 프로젝트·복구·언어·시간대를 보존하도록 AppData 가상화 정책을 명시했습니다. 제한 기능은 Store 제출 시 사용 사유와 승인이 필요합니다.
- 실제 Store 패키지에서 실행된 앱은 Microsoft Store로 업데이트를 안내합니다. Mac·기존 EXE의 GitHub 업데이트는 유지합니다.
- Mac CSR·Developer ID Application 인증서 발급·P12 내보내기·공증 자격 증명·GitHub Environment Secrets 등록 가이드를 추가했습니다.

## 0.7.3

- CI 플랫폼 선택(`all`·`mac`·`win`)을 추가했습니다. Mac만 서명·공증할 때 Windows 인증서를 요구하지 않습니다.
- 서명된 설치 파일도 선택한 모든 아키텍처의 설치·업데이트·제거·재설치 데이터 보존 검증 후 자동 공개할 수 있습니다.
- Mac DMG·ZIP 안의 앱 서명·Gatekeeper·공증 티켓을 확인하며 검증 기록을 실제 패키지 SHA-256과 연결합니다. 공개 전 업로드한 파일의 크기·해시도 확인합니다.
- 기존 서명 없는 배포와 과거 빌드의 공개 재시도를 유지합니다. 이미 공개된 버전은 덮어쓰지 않습니다.
- 일부 플랫폼만 새 버전을 공개해도 업데이트 안내는 사용자의 OS·아키텍처에 맞는 최신 설치 파일을 찾습니다.

## 0.7.2

- 파일 옵션과 네이티브 메뉴에 수동 업데이트 확인 추가. 웹 릴리스·초안·사전 릴리스 제외, 숫자 버전 비교, 공식 GitHub 주소와 운영체제별 설치 파일·체크섬 검사.
- 파일 옵션에서 항목을 선택하면 메뉴를 자동으로 닫아 열린 입력창을 가리지 않도록 개선.
- 오프라인·시간 초과·과도한 응답·잘못된 릴리스 정보 처리. 렌더러의 네트워크 접근이나 자동 설치 권한은 추가하지 않음.
- Windows·Mac ARM64·Intel의 실제 설치·0.7.1에서 업데이트·제거·재설치와 프로젝트·복구·시간대·언어 보존 CI 추가.
- 기존 프로젝트 파일 형식 유지. 사용자 요청이 없는 업데이트 조회·프로젝트 전송 없음.

## 0.7.1

- 업무 기준 시간대 설정, 커밋 원본 기반 패키지 검증과 서명·공증 검사 개선.
- Windows·Mac의 서명 없는 설치 파일, SHA-256 및 원본 커밋 기록 제공.
