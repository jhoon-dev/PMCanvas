# PM Canvas 앱 개인정보처리방침 / Privacy policy

시행일 / Effective date: 2026-10-31  
개발자 / Publisher: JIN HOON KIM

이 페이지의 본문은 Windows·macOS용 PM Canvas Desktop의 방침입니다. iPhone·Android용 PM Canvas Mobile의 방침은 [모바일 개인정보처리방침](../mobile/PRIVACY.md)에서 확인할 수 있으며 앱 안에서도 오프라인으로 제공됩니다. 모바일 앱은 프로젝트를 기기에 저장하며 개발자 서버로 자동 수집·전송하지 않습니다. 사용자가 내보내기·공유 대상으로 선택한 서비스는 해당 서비스의 방침에 따라 파일을 처리합니다.

The policy below covers PM Canvas Desktop for Windows and macOS. For PM Canvas Mobile on iPhone and Android, see the [mobile privacy policy](../mobile/PRIVACY.md), also available offline inside the app. Mobile projects remain on the device and are not automatically collected or sent to the developer's server. Services chosen by the user to export or share files process those files under their own policies.

## 한국어

### 적용 범위와 처리 목적

이 방침은 Windows·macOS용 **PM Canvas Desktop**에 적용됩니다. 별도로 설치·운영하는 PM Canvas 웹 서버의 데이터 처리에는 적용되지 않습니다.

앱은 사용자가 입력하거나 파일에서 가져온 프로젝트명, 참여인력 이름·역할, 업무·일정·메모, 예상 공수와 완료 기록을 처리합니다. 이 정보는 계획·진척률·예상 일정 계산, 화면 표시, 프로젝트 저장·복구와 보고서 생성에 사용됩니다. 참여인력 이름이나 메모에는 개인정보가 포함될 수 있습니다. 앱은 별도 사용자 계정, 연락처 목록, 위치, 카메라 또는 마이크를 요구하지 않습니다.

### 저장과 외부 전송

Mac App Store 설치본은 GitHub 업데이트 API를 조회하거나 설치 파일을 내려받지 않고 Mac App Store 업데이트 화면을 엽니다. Apple의 설치·업데이트·진단 처리는 [Apple 개인정보 처리방침](https://www.apple.com/legal/privacy/)을 따릅니다. 사용자가 선택한 프로젝트의 파일 접근 권한을 다시 사용하기 위한 보안 북마크는 앱의 로컬 컨테이너에 보관합니다. 아래 GitHub 업데이트 설명은 Store 외부 배포본에만 적용됩니다.

- 프로젝트와 내보낸 `.pmcanvas`·JSON·Excel·CSV 파일은 사용자가 선택한 위치에 저장합니다. 복구 사본, 최근 파일 경로, 언어·시간대·업데이트 설정과 업데이트 캐시는 운영체제의 앱 사용자 데이터 영역에 저장합니다. 손상된 설정·복구 파일을 보존한 사본도 남을 수 있습니다.
- 개발자는 앱을 통해 프로젝트 내용이나 파일 경로를 개발자 서버로 자동 수집·전송하지 않습니다. 앱에 광고·사용 행태 추적·자동 오류 보고 기능은 없습니다.
- Microsoft Store 설치본은 Windows Store API로 업데이트를 확인하고 Store 업데이트 화면을 엽니다. Microsoft의 설치·업데이트·진단·백업 처리는 [Microsoft 개인정보처리방침](https://privacy.microsoft.com/privacystatement)을 따릅니다.
- 기존 EXE 및 Mac 배포본은 설정에 따라 시작 시 또는 수동으로 GitHub의 공개 릴리스 API를 조회하고, 사용자가 요청하면 해당 설치 파일을 내려받습니다. 프로젝트 내용·참여인력·파일 경로는 이 요청에 포함하지 않습니다. GitHub 등 접속 대상에는 IP 주소와 일반적인 접속 정보가 전달될 수 있습니다. 앱에서 이 정책이나 지원 링크를 열 때에도 브라우저를 통해 GitHub에 접속합니다. [GitHub 개인정보처리방침](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)이 적용됩니다.
- 사용자가 OneDrive, 다른 동기화·백업 서비스, 네트워크 폴더를 저장 위치로 선택하거나 운영체제 백업을 설정한 경우에는 해당 서비스가 파일을 처리할 수 있습니다. 앱 개발자가 이 서비스를 운영하거나 사용자의 공유 대상을 결정하지 않습니다.

### 보관, 삭제와 보안

프로젝트 파일과 복구·설정 사본은 자동으로 서버에 보관하지 않습니다. PC에 있는 파일의 보관 기간은 사용자가 관리합니다. 앱 제거가 프로젝트나 모든 복구·설정 사본을 삭제하는 것은 아닙니다. 삭제하려면 앱을 종료한 뒤 본인이 저장한 파일, 앱 사용자 데이터 및 별도로 만든 내보내기·동기화·백업 사본을 함께 확인하세요. GitHub 설치 파일 업데이트 캐시는 기본적으로 7일, 완료된 다운로드 2개와 총 1GiB 한도 내에서 정리하며 진행 중이거나 현재 사용하는 파일을 보호합니다.

프로젝트·복구 JSON과 내보낸 파일에는 앱 자체의 암호화나 비밀번호 보호가 없습니다. PC 계정 권한, 디스크 보호와 저장·공유 위치의 접근 권한을 관리하세요. 개발자에게 원격 삭제를 요청하더라도 개발자는 사용자의 로컬 프로젝트에 접근해 삭제할 수 없습니다.

### 지원과 변경

지원 및 개인정보 관련 문의는 [PM Canvas GitHub Issues](https://github.com/jhoon-dev/PMCanvas/issues)에서 받습니다. Issues는 공개되므로 프로젝트 원본, 참여인력 개인정보, 비밀번호·인증 키 또는 민감한 로그를 게시하지 마세요. 사용자가 자발적으로 게시한 문의 내용과 GitHub 계정 정보는 문의 확인·응답에 사용되며 GitHub에도 보관됩니다. 앱의 처리 방식이 바뀌면 이 문서와 시행일을 갱신합니다.

## English

### Scope and purpose

This policy covers **PM Canvas Desktop** for Windows and macOS. It does not cover independently operated PM Canvas web servers.

The app processes project names, team members' names and roles, tasks, schedules, notes, estimated hours and completion records entered by the user or imported from files. It uses this information for planning, progress and forecast calculations, display, saving and recovery, and report generation. Names and notes may contain personal information. The app does not require its own user account, contacts, location, camera or microphone.

### Storage and third parties

Mac App Store installations open the Mac App Store updates page without querying GitHub update APIs or downloading installers. Apple's installation, update and diagnostic processing follows the [Apple Privacy Policy](https://www.apple.com/legal/privacy/). Security-scoped bookmarks used to restore access to the selected project are stored locally in the app container. The GitHub update description below applies only to builds distributed outside the Store.

- Projects and exported `.pmcanvas`, JSON, Excel and CSV files are saved to locations selected by the user. Recovery copies, recent file paths, language, time zone and update preferences, and update caches are stored in the operating system's app user-data area. Preserved copies of damaged preferences or recovery files may remain there.
- The developer does not automatically collect or upload project contents or file paths to a developer server. The app has no advertising, usage tracking or automatic crash reporting feature.
- Microsoft Store installations check for updates through the Windows Store API and open the Store update interface. Microsoft's installation, update, diagnostic and backup processing is governed by the [Microsoft Privacy Statement](https://privacy.microsoft.com/privacystatement).
- Legacy EXE and Mac builds check the public GitHub releases API at startup when enabled or on a manual check, and download installers when requested. These requests do not include project contents, team members or file paths. GitHub and other contacted services may receive an IP address and ordinary connection information. Opening this policy or support links also connects the browser to GitHub. The [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) applies.
- Cloud synchronization, operating system backups and network storage chosen or configured by the user may process the saved files under those services' policies. The developer does not operate those services or choose the user's sharing recipients.

### Retention, deletion and security

Projects, recovery files and preferences are not automatically retained on a developer server. Users control retention on their devices. Uninstalling the app does not necessarily delete project files or all recovery and preference copies. To remove data, close the app and review your saved files, app user-data area and separate exports, synchronized copies and backups. GitHub installer caches are normally cleaned using a seven-day retention, a maximum of two completed downloads and a total limit of 1 GiB, while protecting active and current files.

Project and recovery JSON and exported files are not encrypted or password-protected by the app. Protect your device account, disk and storage or sharing permissions. The developer cannot remotely access or delete your local projects.

### Support and changes

Contact the developer through [PM Canvas GitHub Issues](https://github.com/jhoon-dev/PMCanvas/issues) for support or privacy questions. Issues are public: do not post original projects, team members' personal details, passwords, authentication keys or sensitive logs. Information you voluntarily submit and your GitHub account details are used to understand and respond to your request and are also retained by GitHub. This document and its effective date will be updated when the app's processing changes.
