# Security

Do not post passwords, tokens, MFA setup keys, recovery codes, database dumps, or live authentication configuration in public issues.

Report vulnerabilities privately using the repository's Security → Report a vulnerability feature, when available. If it is unavailable, arrange a private channel with the repository owner before sharing technical details.

Use HTTPS, configure exact trusted proxy addresses, retain the MFA encryption key separately from the database backup, and follow [deployment security](docs/SECURITY.md).
