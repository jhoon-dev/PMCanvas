# Excel 입출력 · 0.21.0

프로젝트를 선택하고 **파일 → Excel 내보내기 / Excel 가져오기**를 사용하세요. 업무 · 일정의 **더 보기**에서도 같은 기능을 사용할 수 있습니다. 내보내기는 조회 권한, 가져오기는 편집 권한이 필요합니다.

## 내보내기와 양식

보고 기준일·검색·담당자 필터를 적용한 XLSX 파일을 내려받습니다. 안내·WBS·세부 작업·간트와 기존 계층·기준 계획 정보를 포함합니다. 날짜·공수·진척률은 Excel 데이터 형식이며 사용자 입력은 수식으로 실행하지 않는 문자열로 저장합니다. 유효한 미저장 초안도 출력할 수 있습니다.

가져오기 창의 **Excel 입력 양식 받기**에서 새 업무용 양식을 받습니다. WBS 시트에 업무명·시작일·종료일·공수를 입력하고, 담당자는 프로젝트의 참여인력 목록에서 선택하거나 비워 두세요. 업무 ID는 새 업무 추가 시 비워도 됩니다. 기존 업무를 수정할 때는 내보낸 파일의 ID를 유지합니다.

## 가져오기

1. XLSX 파일과 시트를 선택합니다. WBS 시트와 한·영 머리글은 자동 연결됩니다.
2. 새 업무 추가 또는 업무 ID를 사용한 기존 업무 갱신을 선택하고 열 연결을 확인합니다.
3. 미리보기에서 오류와 변경 내용을 확인합니다. 오류가 있으면 적용할 수 없습니다.
4. **초안에 적용**한 뒤 **WBS 저장**을 누릅니다. 적용 전에는 서버 데이터를 바꾸지 않습니다.

갱신은 파일에 있는 업무만 수정합니다. 생략한 업무·완료 기록·변경하지 않은 세부 작업은 유지합니다. 완료한 공수나 여러 세부 작업의 총공수 변경은 기존 보호 규칙을 따릅니다. 미리보기 후 프로젝트가 바뀌면 새 미리보기가 필요합니다.

## 파일 제한과 보안

XLSX 4MB, 시트 12개, 각 시트 머리글 포함 501행·40열, 셀 2,000자까지 지원합니다. 실제 압축 해제 총량은 32MB입니다. 손상된 CRC·중복 경로·암호화·수식/오류 셀·매크로·내장 개체·외부 연결·DTD는 거절합니다. Excel에서 **값으로 붙여넣기**한 파일을 사용하세요. XLS·XLSM은 지원하지 않습니다.

파일 처리는 메모리·시간·동시 실행 제한을 가진 별도 프로세스에서 수행합니다. API는 로그인·프로젝트 접근·CSRF·편집 권한을 검사합니다. 전체 복원은 기존 JSON/DB 백업을 사용합니다. CSV 출력도 유지합니다.

API: POST api/projects/:id/export.xlsx, POST api/projects/:id/import-excel, POST api/projects/:id/template.xlsx.
