# 웹 0.21.4 · 데스크톱 0.7.0

2026-10-28 Windows 작업 환경에서 검증했습니다.

- 웹 단위·요청 테스트 227개, 브라우저 시나리오 16개 통과. 회원가입·메일 인증·관리자 MFA 승인·업무 등록·완료 체크·Excel 입출력·동시 수정·영어·모바일·500개 업무를 포함합니다.
- 데스크톱 단위 테스트 32개, 날짜·언어 브라우저 회귀 4개 통과. 자정 이후 완료일, 기본 날짜 갱신 지연, 과거 날짜·사용자 조회 기간, 열린 입력창과 한국어 데이터 보존을 확인했습니다.
- 데스크톱의 전체 화면 사용 흐름과 Electron 개발 실행에서 기존 WBS·기준 계획·일정 조정·실행 취소/다시 실행·일괄 작업·저장·재시작·CSV/XLSX 흐름을 확인했습니다.
- 양쪽 의존성 감사는 보고된 취약점 0건입니다. 공개 파일 검사에는 서명 키·프로비저닝 파일과 데스크톱 환경 예제의 인증 정보 검사를 추가했습니다.
- 정식 배포 정책은 미커밋·스테이징·미추적 소스와 서명 정보 누락을 거절하는지 검사했습니다. macOS는 완성된 공증 인증 그룹도 필요합니다.

푸시·PR의 데스크톱 CI는 Windows·macOS에서 위 검증과 빌드 후 패키지 허용 목록·체크섬·실제 실행을 수행하도록 구성했습니다. 주간 의존성 감사는 양쪽 제품을 검사합니다. 서명 배포는 별도 수동 실행과 desktop-release Environment의 인증 정보가 필요합니다.

실제 인증서·Apple 공증 인증 정보는 이 작업에서 제공되지 않았습니다. [설정 안내](../../../desktop/SIGNING.md)와 예제를 준비했으며 실제 서명·공증 및 정식 설치 파일의 OS 신뢰 검증은 해당 인증 정보를 설정한 뒤 수행해야 합니다. 개발용 Windows 설치 파일의 생성·패키지 실행은 실제 서명을 의미하지 않습니다.
