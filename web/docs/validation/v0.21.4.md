# 웹 0.21.4 · 데스크톱 0.7.0

2026-10-28 Windows 작업 환경에서 검증했습니다.

- 웹 단위·요청 테스트 227개, 브라우저 시나리오 16개 통과. 회원가입·메일 인증·관리자 MFA 승인·업무 등록·완료 체크·Excel 입출력·동시 수정·영어·모바일·500개 업무를 포함합니다.
- 데스크톱 단위 테스트 32개, 날짜·언어 브라우저 회귀 4개 통과. 자정 이후 완료일, 기본 날짜 갱신 지연, 과거 날짜·사용자 조회 기간, 열린 입력창과 한국어 데이터 보존을 확인했습니다.
- 데스크톱의 전체 화면 사용 흐름과 Electron 개발 실행에서 기존 WBS·기준 계획·일정 조정·실행 취소/다시 실행·일괄 작업·저장·재시작·CSV/XLSX 흐름을 확인했습니다.
- 양쪽 의존성 감사는 보고된 취약점 0건입니다. 공개 파일 검사에는 서명 키·프로비저닝 파일과 데스크톱 환경 예제의 인증 정보 검사를 추가했습니다.
- 정식 배포 정책은 미커밋·스테이징·미추적 소스와 서명 정보 누락을 거절하는지 검사했습니다. macOS는 완성된 공증 인증 그룹도 필요합니다.

푸시·PR의 데스크톱 CI는 Windows·macOS에서 위 검증과 빌드 후 패키지 허용 목록·체크섬·실제 실행을 수행하도록 구성했습니다. 주간 의존성 감사는 양쪽 제품을 검사합니다. 서명 배포는 별도 수동 실행과 desktop-release Environment의 인증 정보가 필요합니다.

실제 인증서·Apple 공증 인증 정보는 이 작업에서 제공되지 않았습니다. [설정 안내](../../../desktop/SIGNING.md)와 예제를 준비했으며 실제 서명·공증 및 정식 설치 파일의 OS 신뢰 검증은 해당 인증 정보를 설정한 뒤 수행해야 합니다. 개발용 Windows 설치 파일의 생성·패키지 실행은 실제 서명을 의미하지 않습니다.

## 최종 확인

- [데스크톱 CI](https://github.com/jhoon-dev/PMCanvas/actions/runs/40645878863): Windows x64·macOS arm64에서 단위·화면·날짜/언어·개발 앱·패키징 후 파일 허용 목록/체크섬 및 실제 앱 실행 모두 통과했습니다. macOS 프로필 격리는 `/var`와 `/private/var` 같은 별칭의 실제 경로를 비교합니다. 앱 리소스는 허용 목록에 한해 ASAR를 지원하는 파일 읽기로 제공합니다.
- [웹 CI](https://github.com/jhoon-dev/PMCanvas/actions/runs/40645878924)와 [CodeQL](https://github.com/jhoon-dev/PMCanvas/actions/runs/40645879033) 통과. 웹 CI에는 실제 PostgreSQL 21개, HTTP·TLS SMTP 15개와 백업·복원 검증도 포함합니다.
- Windows 개발용 설치 파일을 만들고 패키지의 모든 앱 소스 체크섬과 실제 실행을 로컬에서도 확인했습니다. 버전·기준 소스 커밋·개발 빌드 표시와 SHA-256 목록을 함께 보관했습니다. 사용자 PC에 새 설치 파일을 설치하거나 제거한 검증은 이번 범위에 포함하지 않습니다.
- 운영 웹 0.21.4 반영 완료. 배포 전 DB 덤프와 별도 위치의 설정·키 복구본, 이전 이미지를 보존했습니다. 동일 DB 볼륨·암호화 키를 확인했고, 계정·프로젝트·업무·완료 항목 등 13개 테이블의 행 수와 내용 해시가 배포 전후 일치했습니다. 마이그레이션은 기존 15개를 유지합니다. 갱신 후 상태·실제 응답 파일·인증 경계와 일반 백업 명령도 확인했습니다.

서명 자격 증명 없는 정식 Windows 배포 사전 검사가 중단되는 것도 확인했습니다. macOS 공증과 서명된 DMG 설치, Intel Mac 실행 및 OS별 정식 업그레이드·제거 검증은 인증 정보와 해당 환경에서 추가 수행해야 합니다.
