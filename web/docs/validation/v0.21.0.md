# 웹 0.21.0 · 데스크톱 0.2.0 검증

2026-10-28 Windows에서 완료했습니다.

- 웹 단위·요청 테스트 221개, 실제 브라우저 시나리오 13개 통과.
- 실제 HTTP·TLS SMTP 테스트 15개 통과. 새 프로덕션 Docker 이미지에서도 non-root·읽기 전용 파일 시스템·네트워크 차단 상태로 양식 생성·가져오기·내보내기를 확인했습니다.
- 데스크톱 파일·모델·보고서·XLSX 테스트 15개 통과.
- 데스크톱 화면 검증은 1440px·1000px에서 기존 사용 흐름과 보고서 형식 선택을 확인했습니다.
- 실제 Electron 개발 실행과 패키징된 Windows EXE에서 XLSX 저장, 양식 생성, 네이티브 파일 선택, 열 연결·미리보기·적용, 파일 저장·재시작을 확인했습니다. 임시 사용자 프로필과 테스트 문서만 사용했습니다.
- electron-builder 26.18.0으로 개발용 Windows x64 NSIS 설치 파일을 생성했습니다. 새 출력 폴더를 사용해 이전 배포 파일을 보존했습니다. 새 설치 파일의 시스템 설치·제거와 macOS 실행 검증은 이번 범위에 포함하지 않습니다.
- 패키징된 ASAR의 앱 파일 허용 목록·필수 모듈·버전·개발 의존성 제외 검사를 통과했습니다.
- 포맷·공개 파일 검사와 양쪽 npm audit 검사를 통과했습니다. 감사에서 보고된 취약점은 두 제품 모두 0건입니다.

XLSX 검증에는 입력 양식의 날짜·숫자·담당자 목록, 영어 머리글 자동 연결, 미확정 가져오기의 문서 보존, 완료 기록과 복수 세부 작업 보존, 오래된 미리보기·재선택 경합·시간 초과·잘못된 ID/날짜·파일 크기 제한을 포함했습니다. 수식·CRC 손상·문자 참조로 숨긴 외부 관계·매크로 MIME·내장 개체·DTD·대소문자 중복 항목은 거절했습니다.

위 개발 검증에서는 운영 데이터를 테스트에 사용하지 않았습니다. 이후 Windows 현재 사용자 설치·제거·재설치 검증 기록도 확인했으며 상세 범위는 [데스크톱 README](../../../desktop/README.md)에 기록했습니다.

## 운영 반영 · 2026-10-28

웹·데스크톱·공통 코드 분리와 Excel 개선을 함께 커밋해 GitHub main에 반영했습니다. 배포 직전 웹 221개·데스크톱 15개 테스트와 포맷·공개 파일 검사를 다시 통과했습니다.

DB 덤프를 생성해 `pg_restore --list`로 확인하고, 설정·키는 저장소 및 덤프 폴더 밖의 현재 Windows 사용자 전용 복구 위치에 따로 보존했습니다. 이전 앱·백업 이미지도 롤백용으로 보존했습니다. 폴더 이동으로 기존 DB 컨테이너의 옛 바인드 경로가 사라져 배포 전 덤프는 `docker exec` 스트림으로 받았습니다. 새 Compose로 갱신한 뒤 일반 백업 명령도 다시 통과했습니다.

운영 앱·백업 서비스를 0.21.0 소스로 갱신했습니다. 컨테이너 재생성 전후 동일한 DB 볼륨과 암호화 키를 사용하는지 확인했습니다. 계정·MFA·인력·프로젝트·공유·업무·완료 항목·휴지통·외부 계정·메일 설정·알림 설정·마이그레이션의 13개 테이블에서 행 수와 내용 해시가 모두 일치했습니다. 마이그레이션은 기존 15개를 유지합니다.

실행 중인 앱의 버전 0.21.0, DB·앱 상태, 백업 프로세스 실행, HTTP 상태, 배포 소스와 실제 응답 파일의 일치, 공유 Excel 모듈 제공, CSP 및 미인증 API 차단을 확인했습니다. 운영 계정으로 새 MFA 등록이나 업무 생성은 하지 않았습니다.

배포 소스 커밋은 `348465b`입니다. GitHub의 [테스트·의존성·실제 PostgreSQL·백업 복원 검증](https://github.com/jhoon-dev/PMCanvas/actions/runs/40617469455)과 [CodeQL](https://github.com/jhoon-dev/PMCanvas/actions/runs/40617469397)이 모두 통과했습니다. CI에서 웹 221개·HTTP 15개·PostgreSQL 21개·복원 1개·브라우저 13개를 확인했으며, 별도로 로컬 데스크톱 15개를 다시 통과했습니다.
