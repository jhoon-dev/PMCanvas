# 업무 · 일정 사용법 (0.11.0)

왼쪽 **업무 · 일정**에서 **업무 추가 → 표 입력 → 저장** 순서로 사용합니다. 표와 간트는 같은 초안을 편집합니다. 저장하면 진척률·오늘 할 일·예상 완료일에도 반영됩니다.

## 기본 입력

기본 표에는 업무명·담당자·시작일·종료일·공수 5개 입력 열과 진척률을 표시합니다. 셀을 눌러 바로 수정하세요. **업무 추가**는 미지정 담당자와 기본 8시간 작업 한 개를 가진 행을 만들고 업무명에 커서를 둡니다. 대시보드의 업무 추가도 같은 표로 연결됩니다.

- Tab / Shift+Tab: 다음·이전 셀. Enter / Shift+Enter와 Alt+위·아래: 행 이동. 마지막 행 다음으로 이동하면 새 행 추가.
- Ctrl+S (Mac: Cmd+S): 저장. Ctrl+Z / Ctrl+Y: 실행 취소·다시 실행. 최근 20개 작업을 보관하며 입력 중인 셀에서는 브라우저 텍스트 실행 취소가 우선합니다.
- 여러 세부 작업이나 완료 기록이 있는 업무의 공수는 표에서 읽기 전용입니다. 저장 후 해당 행의 **상세**에서 세부 작업별 시간을 수정하세요.
- 행 체크박스를 선택하면 복제·삭제·선택 해제가 나타납니다. **계층 · 순서**에서 하위 업무로 묶기·한 단계 위로·위아래 이동을 사용합니다.

복제는 새 ID와 미완료 작업을 만들며 함께 복제한 업무의 선행 관계를 연결합니다. 삭제는 후속 업무의 선행 참조를 해제합니다. 저장 전에는 실행 취소할 수 있습니다. 계층·집계 규칙은 [일정 관리 안내](PLANNING.md)를 참고하세요.

## 필요한 도구 펼치기

| 위치 | 기능 |
|---|---|
| 더 보기 | Excel 내려받기·가져오기, CSV 내려받기, 표 복사 |
| 더 보기 → 단계 · 선행 업무 · 메모 표시 | 전체 입력 열과 예상 완료일 |
| 더 보기 → 계획 · 관리 | 기준 계획 저장·삭제, 상세 양식으로 업무 추가, 변경 취소·서버 다시 읽기 |
| 일정 → 일정 옵션 | 예상 일정·분석 표시, 후속 업무 함께 조정, 선택 일정 이동, 선행 일정 맞추기 |
| 아래 일정 점검 | 선행 충돌·담당자 과부하, 기준 계획 비교, 임계 업무와 계산 기준 |
| 상단 파일 | 현재 프로젝트 JSON 백업·백업 불러오기 |
| 대시보드 → 프로젝트 관리 | 변경 이력·공유·설정 |

분석 표시는 기본으로 꺼져 있습니다. 실선 막대는 계획과 진척입니다. **예상 일정과 분석 표시**를 켜면 예상 일정 점선·선행 화살표·기준 계획 회색 선·임계 업무 빨간 테두리·하위 포함 초록 선을 함께 보여 줍니다. 날짜와 일·주·월 보기 배율은 표 위와 일정 위에서 바꿉니다.

## Excel 붙여넣기

Excel 영역을 복사해 표의 시작 셀에 붙여넣습니다. 기존 행을 순서대로 덮어쓰고 부족한 행은 추가합니다. 검색 중에는 표시 행이 대상이며 적용 후 검색 조건을 해제해 결과를 보여 줍니다. 새 업무만 추가하려면 표 아래 **여러 업무 붙여넣기**를 펼치세요.

기본 열 순서: **업무명 → 담당자 → 시작일 → 종료일 → 공수(h)**.

전체 열 순서: **업무명 → 단계 → 담당자 → 시작일 → 종료일 → 공수(h) → 선행 업무 → 메모**.

기본 표에서 5열을 넘는 데이터를 붙여넣으면 전체 열 형식으로 처리하고 열을 펼칩니다. 기본 5열 붙여넣기는 숨겨진 단계·선행·메모를 보존합니다. 앞부분 열만 붙여넣을 수 있고, 생략한 열은 기존 값 또는 새 업무 기본값을 사용합니다. 정확한 5열·8열 머리글은 제외합니다.

탭으로 열, 줄바꿈으로 행을 구분하며 따옴표로 묶인 여러 줄 메모도 처리합니다. 날짜는 YYYY-MM-DD / YYYY/MM/DD / YYYY.MM.DD를 지원합니다. 담당자는 등록한 이름 또는 ID, 선행 업무는 행 번호·고유 ID·중복되지 않는 이름을 사용합니다. 공수를 바꿀 수 없는 완료 업무를 포함하거나 값이 잘못되면 전체 붙여넣기를 취소합니다. 한 번에 500행·1MB, 프로젝트 최대 500업무입니다.

**표 복사**는 선택한 표시 행, 선택이 없으면 표시된 전체 행과 현재 열을 TSV로 복사합니다. 수식처럼 해석될 수 있는 텍스트는 일반 텍스트로 처리합니다. 출력과 복사는 서버 저장을 대신하지 않습니다. XLSX는 [Excel 안내](EXCEL.md)와 [가져오기 안내](PLANNING.md)를 참고하세요.

## 일정 바꾸기

간트 막대 가운데를 끌어 시작·종료를 함께 이동하고 양 끝으로 기간을 조절합니다. 방향키는 하루 이동, Shift+방향키는 종료일, Alt+방향키는 시작일을 조절합니다. 여러 행을 선택하고 선택 막대를 옮기면 함께 이동합니다. **일정 옵션 → 선택 일정 이동**에 양수·음수 일수를 넣어도 됩니다.

단위는 달력일입니다. 시작일 ≤ 종료일과 최소 한 근무일을 검증하며 휴무일·인력 가용량·완료 기록에 따른 예상일도 갱신합니다. 후속 업무 함께 조정은 선행 종료 다음 근무일보다 일찍 시작하는 후속 일정을 뒤로 밀고 기간 길이를 유지합니다. 앞당기기는 자동 적용하지 않습니다. 선행 순환은 허용하지 않습니다.

## 저장과 복구

동시 저장 충돌이 발생하면 **변경사항 비교**가 열립니다. 마지막으로 읽은 값·내 초안·서버 최신 값을 비교해 서로 다른 필드 변경은 합칩니다. 같은 필드, 삭제와 수정, 양쪽에서 달라진 업무 순서는 유지할 쪽을 선택합니다. 적용한 결과는 WBS 초안에서 확인한 뒤 저장하세요. 닫으면 내 초안을 유지합니다. 선택 결과에 삭제된 담당자·선행 업무 참조나 계층 순환이 생기면 적용을 막습니다. 비교 후 다시 누군가 저장해도 서버 revision 검사로 덮어쓰지 않습니다.

저장 전 화면·프로젝트 전환과 자동 갱신을 제한합니다. 계정·프로젝트별 탭 초안을 자동 보관하고 새로고침 후 복구 버튼을 제공합니다. 8시간 후 만료하며 브라우저 종료 후 보관은 계정 설정에서 선택합니다. 로그아웃 시 삭제합니다. [보안 안내](SECURITY.md)를 참고하세요.

저장 오류나 동시 수정 충돌 시 초안을 유지하고 자동 덮어쓰기를 하지 않습니다. 상단 파일에서 JSON 백업 후 **더 보기 → 변경 취소 · 서버에서 다시 읽기**로 최신 버전을 가져오세요. 잘못된 입력은 저장을 막고 셀 오류로 알립니다. JSON의 _wbsPendingCells는 확인용이며 잘못된 값을 가져오기로 자동 적용하지 않습니다.

조회자는 표·간트 조회와 복사·출력을 사용할 수 있으며 업무와 일정을 수정할 수 없습니다. 현재 기준 계획은 프로젝트당 한 벌이고 자원 자동 최적화는 제공하지 않습니다.
