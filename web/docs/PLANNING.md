# 일정 관리 확장 · 0.9.0

## 자동 초안 복구

WBS 입력을 계정·프로젝트별로 현재 탭에 자동 보관합니다. 0.10.0부터 브라우저 종료 후 보관은 계정 관리에서 선택하며, 8시간 만료와 로그아웃 시 삭제를 적용합니다. [보안 운영 안내](SECURITY.md)를 참고하세요. 새로고침 뒤 WBS 화면에서 **초안 복구**를 눌러 복원합니다. 아직 확정되지 않은 셀 값도 보관합니다. 복구는 서버에 자동 저장하지 않습니다. 서버 버전이 달라졌으면 이전 revision을 유지하므로 덮어쓰기 대신 저장 충돌로 보호합니다. JSON 백업 후 최신 서버 내용과 비교하세요.

저장 성공 또는 명시적인 변경 취소 후 보관 사본을 삭제합니다. **보관 초안 삭제**는 보관된 복구 사본을 지웁니다. 저장 공간 부족은 화면에 표시하며 메모리 초안은 유지합니다. 브라우저 데이터 삭제·다른 기기·다른 브라우저에서는 복구할 수 없습니다. 공용 PC에는 업무 초안이 남을 수 있으므로 저장 또는 삭제 후 이용을 마치세요.

0.11.0부터 추가 열과 기준 계획은 **더 보기**, 간트의 예상·기준·임계 표시와 후속 일정 조정은 **일정 옵션**에서 펼칩니다. 일정 충돌·과부하의 요약은 아래 **일정 점검**에 표시합니다.

## 계층형 WBS

행을 선택한 뒤 **계층 · 순서 → 하위 업무로**를 누르면 앞의 같은 수준 업무 아래로 묶습니다. **한 단계 위로**로 한 단계 올립니다. 1 / 1.1 / 1.2 형식 번호와 접기·펼치기, 최대 20단계를 지원합니다. 검색 중에는 일치하는 하위 업무를 접힘 상태와 관계없이 표시합니다.

상위 행 합계는 **자체 작업과 모든 하위 작업**의 공수·완료 공수를 한 번씩 합산합니다. 입력 칸은 자체 작업의 일정·공수이고, 합계 배지는 하위 포함 일정·가중 진척률입니다. 기존 상위 업무의 실제 작업과 완료 기록을 없애지 않습니다. 전체 프로젝트 공수는 자체 작업만 합산하므로 중복 집계하지 않습니다. 간트 위쪽 초록 선은 하위 포함 일정입니다. 부모 행만 삭제하면 자식은 최상위로 이동하며 자식의 작업은 유지합니다. 상세 편집에서 상위 행을 삭제하려면 하위 업무를 먼저 정리하세요.

## 일정 충돌과 과부하

일정 점검 패널에서 선행 업무의 계획 종료일 이전에 시작하는 업무를 표시합니다. 담당자의 일별 가용시간은 일 근무시간 × 투입률이며, 업무 공수는 계획 기간의 근무일에 균등 배분합니다. 같은 담당자의 공수 합계가 이를 초과하는 기간을 과부하로 표시합니다. 주말·등록 휴무일은 제외합니다. 이는 계획 업무량 점검이며 실제 근무시간 기록이 아닙니다.

## 기준 계획 비교

**더 보기 → 현재 일정을 기준 계획으로 저장**으로 현재 업무 ID·이름·일정·공수·계층을 한 벌 보관합니다. **저장**을 눌러야 서버에 반영됩니다. 이후 시작·종료 차이(달력일), 공수 차이, 추가·삭제·이름·상위 변경을 비교하며 간트 하단 회색 선으로 기준 일정을 표시합니다. + 날짜 차이는 지연입니다. 기존 기준을 교체하거나 삭제하기 전 확인하며, 서버 저장 전에는 실행 취소할 수 있습니다. 기준 계획은 프로젝트당 한 벌입니다.

## 임계 경로

간트의 빨간 테두리는 여유일 0인 임계 업무입니다. CPM 계산은 계획 기간의 근무일, 현재 시작일 제약, 기존 완료→시작 선행 관계를 사용합니다. 여러 임계 분기가 있으면 모두 표시합니다. 담당자 경쟁에 따른 자원 평준화는 CPM에 포함하지 않으므로 과부하 경고와 함께 판단하세요.

## Excel 가져오기

업무 · 일정의 **더 보기 → Excel 가져오기** → 파일 선택 → 시트 선택 → 열 연결 → **미리보기** → **초안에 적용** → **저장** 순서입니다. 잘못된 값은 행 번호와 오류로 표시하며 오류가 있으면 적용하지 않습니다. 적용은 한 번의 실행 취소로 되돌릴 수 있습니다.

- .xlsx / 파일 4MB 이하 / 시트 12개 이하 / 시트별 머리글 1행 + 업무 500행 / 40열 이하
- 큰 간트·상세 시트는 선택할 수 없지만 같은 파일의 WBS 시트를 가져올 수 있습니다.
- 첫 행은 머리글입니다. 업무명·시작일·종료일을 반드시 연결하며 나머지 열은 생략할 수 있습니다.
- 새 업무 추가: 새 ID로 생성하고 파일 내 상위·선행 ID 참조를 새 ID로 연결합니다.
- 기존 업무 갱신: 현재 프로젝트의 업무 ID가 일치하는 행만 갱신합니다. 생략한 업무는 유지합니다. 갱신은 ID 기준이며 이름만으로 덮어쓰지 않습니다.
- 완료 기록이 있거나 세부 작업이 여러 개인 업무의 공수는 같은 값만 허용합니다. 공수 변경은 상세 편집으로 처리하세요. 완료 기록은 가져오기로 삭제하지 않습니다.
- 수식·오류 셀은 값으로 바꿔 주세요. 매크로·외부 연결은 지원하지 않습니다. 서버는 제한된 별도 작업에서 파일을 읽고, 파싱 시 프로젝트를 변경하지 않습니다.

Excel 출력에는 갱신용 업무 ID·상위 업무 ID·선행 업무 ID, 하위 포함 공수·진척률, 임계 여부와 기준 계획 비교 시트가 추가됩니다. 전체 프로젝트 복원은 기존 JSON 백업을 이용하세요.
