# 실제 사용 흐름 데모

저장소 폴더에서 개발 의존성을 설치한 뒤 실행합니다. Docker나 SMTP 서버 설정 없이 체험할 수 있습니다.

```sh
npm ci --ignore-scripts
npm run demo
```

- 앱: http://localhost:4183/pmcanvas/
- 데모 메일함: http://localhost:4182/inbox
- 데모 관리자: `admin@example.com` / `preview-admin-password`

실제 앱의 요청 처리·이메일 발송·화면 코드를 사용하되 저장소는 메모리이며, SMTP 수신기는 로컬 TLS 연결만 사용합니다. 운영 `.env`·DB·메일 설정은 읽지 않고 외부로 메일을 보내지 않습니다. 두 서버는 loopback에서만 열리고 1시간 뒤 종료됩니다. Ctrl+C로 즉시 종료할 수 있으며 다시 실행하면 데이터가 초기화됩니다. 포트 4182·4183을 다른 프로그램에서 사용 중이면 먼저 해당 프로그램을 종료하거나 다른 환경에서 실행하세요.

## 따라 하기

1. 앱의 **회원가입**에서 `demo@example.com`으로 신청합니다.
2. 데모 메일함을 열고 **이메일 인증하기**를 누릅니다. 이름과 12자 이상의 데모용 비밀번호를 입력해 인증합니다. 실제로 쓰는 비밀번호는 입력하지 마세요.
3. 관리자 계정으로 로그인합니다. 첫 로그인에서는 인증 앱 MFA를 등록하고 복구 코드를 보관합니다.
4. **계정 → 관리자 설정 → 사용자**에서 신청을 검토합니다. **프로젝트에 바로 초대하기**를 펼쳐 ‘우리 팀 첫 프로젝트’를 선택하고 승인합니다.
5. 메일함을 새로고침하면 관리자 승인 요청과 가입 승인 안내 메일을 확인할 수 있습니다. 메일 링크를 열기만 해서는 승인되지 않습니다.
6. 관리자가 **프로젝트 한눈에 → 프로젝트 관리 → 공유 → 내 업무에 담당 계정 연결**에서 ‘담당자’를 새 계정과 연결합니다.
7. 관리자를 로그아웃하고 새 계정으로 로그인합니다. **업무 · 일정 → 업무 추가**에서 업무명·담당자·일정을 입력하고 저장합니다. 간트 일정에도 반영됩니다.
8. **내 업무**에서 해당 업무를 열고 완료한 항목을 체크합니다. 완료일과 진척률이 갱신됩니다. 새로고침 후 **완료한 업무**를 펼치면 저장된 결과를 확인할 수 있습니다.

‘우리 팀 첫 프로젝트’와 참여인력 한 명은 데모에 미리 준비되어 있습니다. 실제 운영 환경에서는 프로젝트와 참여인력을 먼저 등록하고 관리자가 SMTP를 설정해야 회원가입 인증 메일을 보낼 수 있습니다.
