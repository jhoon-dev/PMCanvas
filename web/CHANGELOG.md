# 변경 이력

## 0.21.7

- 프로젝트·업무·참여인력 편집창의 변경 감지와 페이지 이탈 확인 추가. 원래 값으로 되돌린 입력·저장·취소는 경고하지 않음.
- 기존 WBS 초안·권한·저장 충돌 보호와 업무·완료 기록 유지. DB 마이그레이션 변경 없음.
- Desktop 0.8.1: Electron 45.1.0 보안 런타임, Ed25519 업데이트 메타데이터 검증·보호된 발행 키, 손상 설정 복구와 업데이트 캐시 재사용·정리 추가.

## 0.21.6

- 빈 프로젝트에는 참여인력·업무 등록·완료 기록 순서로 시작 안내 표시. 업무가 생기면 기존 대시보드로 전환.
- 업무 상세 입력은 이름·담당자·일정·체크리스트를 먼저 표시하고 분류·선행 업무·메모는 펼쳐서 수정. 기존 연결과 메모는 보존하며 자동으로 펼침.
- WBS 검색 필터 초기화 추가. 저장 전 표 입력과 완료 기록을 유지하면서 검색 조건만 해제.
- 글자·입력칸 가독성과 모바일 날짜 입력 개선. 입력 영역만 스크롤하고 저장·취소 버튼은 계속 표시.
- 공통 메뉴·접근성 스타일을 웹·데스크톱에서 함께 사용하고 키보드 초점과 입력창 스크롤 위치 개선.

## 0.21.5

- 계정 비활성화와 프로젝트 변경을 트랜잭션에서 직렬화하고 본문 수신 중 폐기된 세션의 변경 요청을 거절.

- 웹 조직 업무 기준 시간대(`PM_TIME_ZONE`)와 데스크톱 시간대 설정 추가. 기존 일정·완료일 보존.
- Desktop 0.7.1: 확정 커밋으로 격리 빌드, 독립 ASAR 검증, OS 서명·공증 검증 후 최종 앱 실행 검사 추가.

## 0.20.4

- 백업 단계를 고정 코드·표시 이름·실패 종류로 분리. 표시 언어와 문구가 바뀌어도 백업/복원 알림 분류 유지.

- 관리자 운영 알림 화면의 접힌 상세에서 메일 분류별 누적 횟수 제공. 집계·운영 알림·감사 기록을 한 트랜잭션으로 저장하며 원문 SMTP 응답·주소·비밀번호는 진단 기록에 넣지 않음. 기존 알림 횟수와 재시도·확인 동작 유지.

- 백업을 전용 partial 파일로 생성하고 아카이브 검사를 통과한 뒤 덤프로 전환. 생성·검사 실패 시 partial 정리, 비정상 종료로 하루 이상 남은 자동 partial 정리, 복원 점검 실패 시 완성 덤프와 파일명 보존.
