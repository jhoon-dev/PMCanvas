# Excel 출력 (0.8.0)

업무 · 일정 화면의 **더 보기 → Excel 내려받기**을 누르면 .xlsx 파일을 내려받습니다. 현재 보고 기준일과 검색·담당자 필터가 적용됩니다. 저장 전의 유효한 초안도 출력할 수 있으며, 잘못된 셀 값은 먼저 수정해야 합니다.

- 안내: 프로젝트, 보고 기준일, 초안 여부, 공수와 범례
- WBS: 담당자, 계획 날짜, 공수, 진척률, 예상 완료일, 선행 업무, 메모
- 세부 작업: 각 업무의 작업 내역, 공수, 완료일
- 간트: 계획과 예상 일정. 장기 일정은 최대 120칸으로 자동 축약

날짜는 Excel 날짜, 공수와 진척률은 숫자로 저장합니다. 머리글 고정·필터·줄바꿈 서식을 제공합니다. 사용자 입력은 수식으로 실행하지 않는 문자열로 출력합니다. 예상 일정은 필터와 관계없이 전체 프로젝트로 계산합니다.

조회 권한이 있는 프로젝트만 출력할 수 있습니다. 출력은 서버 데이터를 변경하지 않습니다. 0.9.0부터 Excel 수정 내용을 열 연결·미리보기 후 가져올 수 있습니다. [가져오기 안내](PLANNING.md)를 참고하세요. 전체 복원은 기존 JSON 백업을 사용하세요. CSV 출력도 유지됩니다.

API: POST api/projects/:id/export.xlsx (로그인 세션, CSRF, JSON 본문 project/asOf/taskIds 필요).
