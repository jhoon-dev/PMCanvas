# WBS · 간트 편집 (0.7.0)

왼쪽 **WBS · 업무 관리**에서 업무를 표로 입력하고 간트에서 일정을 조정합니다. 여러 변경을 확인한 뒤 **WBS 저장**을 누르면 프로젝트의 한 버전으로 서버에 저장합니다. 다른 화면의 진척률·완료 체크·예상 완료일도 같은 업무 데이터를 사용합니다.

## 업무 입력표

- 셀에서 업무명, 단계, 담당자, 시작일, 종료일, 공수, 선행 업무, 메모를 편집합니다.
- **행 추가**는 기본 8시간짜리 완료 체크 항목 한 개를 가진 업무를 만듭니다. 담당자는 미지정 상태이므로 직접 선택하세요.
- Tab / Shift+Tab은 셀을, Enter / Shift+Enter는 행을 이동합니다. 마지막 행에서 다음 행으로 이동하면 새 행을 추가합니다. Alt+위/아래 화살표도 행 이동에 사용할 수 있습니다.
- Ctrl+S(Mac: Cmd+S)로 저장합니다. 실행 취소·다시 실행은 Ctrl+Z / Ctrl+Y 또는 도구 버튼을 사용하며 최근 20개 작업을 보관합니다. 입력 중인 셀에서는 브라우저의 텍스트 실행 취소가 우선합니다.
- 행 왼쪽 체크박스로 여러 업무를 선택해 복제·삭제·위아래 이동·일정 일괄 이동을 합니다. 행 이동은 표시 순서를 바꾸며 기존 고유 ID와 선행 관계는 유지합니다.
- 복제한 업무는 새 ID와 미완료 세부 작업을 갖습니다. 여러 업무를 함께 복제하면 복제된 업무 사이의 선행 관계도 연결합니다. 삭제 시 후속 업무의 선행 참조를 해제하며 저장 전에는 실행 취소할 수 있습니다.
- **세부 작업**은 저장된 업무의 기존 상세 편집 창을 엽니다. 초안을 먼저 저장해야 합니다.

여러 세부 작업이 있거나 완료 기록이 있는 업무의 합계 공수는 표에서 읽기 전용입니다. 세부 작업별 시간을 바꾸려면 상세 편집을 사용합니다. 공수를 일괄 비례 조정해서 이미 완료한 작업의 비중을 바꾸지 않습니다.

## 엑셀 붙여넣기·복사

엑셀에서 영역을 복사한 뒤 표의 시작 셀에 붙여넣습니다. 기존 행을 순서대로 덮어쓰고 필요한 행이 모자라면 새 업무를 추가합니다. 필터 상태에서는 표시된 행을 기준으로 붙여넣습니다. 붙여넣은 뒤에는 필터가 해제되어 결과 전체를 확인할 수 있습니다.

새 업무만 추가하려면 표 아래 **새 업무 여러 행 붙여넣기** 영역을 사용합니다. 왼쪽부터 다음 순서입니다. 앞의 일부 열만 붙여넣어도 되며 생략한 열에는 기존 값 또는 새 업무 기본값을 사용합니다.

```text
업무명    단계    담당자    시작일    종료일    공수(h)    선행 업무    메모
```

열 구분은 탭, 행 구분은 줄바꿈입니다. 따옴표로 묶인 여러 줄 메모와 탭도 처리합니다. 날짜는 `YYYY-MM-DD`, `YYYY/MM/DD`, `YYYY.MM.DD` 형식을 지원합니다. 선행 업무는 WBS 행 번호, 고유 ID 또는 중복되지 않는 업무명으로 지정합니다. 담당자는 등록한 인력의 이름이나 ID를 사용하며 이름이 중복되면 선택 목록을 사용하세요. 빈 담당자는 미지정, 빈 선행 업무는 없음입니다.

공수만 다른 여러 세부 작업이나 완료된 업무에 덮어쓰려고 하면 전체 붙여넣기를 취소합니다. 어떤 행이 잘못되어도 일부 행만 반영하지 않습니다. 프로젝트 최대 500업무, 한 번의 붙여넣기 500행·1MB 제한을 적용합니다. 단일 셀에 업무명 `업무명`을 붙여넣는 것은 일반 입력이며, 표와 정확히 같은 8열의 머리글만 자동 제외합니다.

**표 복사**는 선택한 표시 행 또는 선택이 없으면 표시된 전체 행을 엑셀에 붙여넣을 수 있는 TSV로 복사합니다. 수식처럼 해석될 수 있는 텍스트는 일반 텍스트로 처리합니다. **CSV 출력**은 현재 WBS 초안과 표시 행의 진척·예상일을 출력합니다. CSV와 클립보드 복사는 서버 저장을 대신하지 않습니다.

## 간트 일정 편집

- 계획 막대 가운데를 끌면 시작·종료일을 함께 이동합니다. 양 끝을 끌면 시작일 또는 종료일을 조절합니다.
- 막대에서 좌우 방향키는 하루 이동, Shift+방향키는 종료일, Alt+방향키는 시작일을 조절합니다. 시작·종료 핸들에 초점이 있으면 그 끝을 조절합니다.
- 여러 행을 선택하고 선택된 막대를 이동하면 선택한 업무들이 함께 움직입니다. **선택 일정 일괄 이동**에 양수·음수 일수를 넣어 같은 작업을 할 수도 있습니다.
- 일·주·월 보기로 배율을 변경합니다. 업무명이 왼쪽에 고정되고 타임라인은 가로로 스크롤됩니다.
- 실선 막대는 계획과 진척률, 점선은 예상 작업 기간, 화살표는 선행 관계입니다. 주말은 음영으로 표시합니다. 등록 휴무일은 계산·검증에 반영합니다.

이동 단위는 달력일입니다. 날짜 변경 후 최소 한 근무일이 있는지 검증하며 시작일이 종료일을 넘는 변경은 반영하지 않습니다. 근무일·휴무일·인력 가용량·완료 기록을 사용하는 기존 예상 완료일 계산도 즉시 갱신합니다. 계획 날짜는 사용자가 편집한 일정, 점선은 계산에 따른 예상 일정이므로 서로 다를 수 있습니다.

**일정 변경 시 후속 업무 밀기**를 켜면 변경한 업무의 후속 업무가 선행 완료 다음 근무일보다 빨리 시작할 때 뒤로 옮깁니다. 후속 업무의 달력일 길이를 유지하며, 선행 일정이 앞당겨져도 후속 일정을 자동으로 당기지는 않습니다. **선행 관계에 맞추기**는 전체 업무에 같은 규칙을 적용합니다. 옵션을 끄면 계획은 유지하고 충돌 건수를 표시합니다. 선행 관계의 순환은 허용하지 않습니다.

## 저장·실행 취소·충돌

초안은 브라우저 메모리에 보관하며 이 화면의 표와 간트에 함께 반영합니다. 저장 전에는 다른 화면·프로젝트로 전환하지 못하게 안내하고 자동 갱신도 멈춥니다. 페이지를 떠나거나 새로고침하면 초안이 소실될 수 있으므로 서버에 저장하거나 JSON 백업을 사용하세요.

저장 오류·409 동시 수정 충돌이 발생하면 초안을 유지하고 자동으로 덮어쓰지 않습니다. JSON 백업 후 **변경 취소 · 새로 읽기**를 사용하면 서버의 최신 버전을 가져옵니다. 다른 사용자가 먼저 수정했을 때 강제 덮어쓰기는 제공하지 않습니다. 조회자는 표·간트를 조회하고 복사·출력할 수 있으며 업무와 일정을 편집할 수 없습니다.

날짜 등 검증을 통과하지 못한 입력 중 셀이 있으면 저장을 막고 오류를 표시합니다. JSON 백업은 유효한 초안과 입력 중 셀을 `_wbsPendingCells`에 함께 보관합니다. 일반 백업 불러오기는 유효한 프로젝트 데이터를 복원하며, 이 별도 기록의 잘못된 셀 입력은 자동 적용하지 않습니다.

이번 버전의 WBS 번호는 업무 행 순서이며 단계는 분류입니다. 다단계 요약 업무·하위 WBS 집계, 임계 경로, 기준 계획 버전, 엑셀 파일 자체의 XLSX 가져오기는 아직 제공하지 않습니다.
