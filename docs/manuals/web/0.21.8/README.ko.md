# PM Canvas 웹 0.21.8 사용 안내

0.21.8은 계정·프로젝트·업무 입력의 새로고침·이탈 보호와 서버 저장 경합을 보완한 버전입니다.

프로젝트 만들기 → 참여인력 → 업무·WBS/일정 → 완료 체크 → 보고서 순서로 사용합니다. 공유에서 계정을 초대하고 인력을 로그인 계정과 연결하면 내 업무에서 담당 작업을 모아 볼 수 있습니다. 미저장 입력은 저장하거나 명시적으로 취소한 뒤 이동하세요. 계정 비밀번호 입력은 브라우저 저장소에 보관하지 않습니다.

메뉴·그래프·투입 계획·주간보고를 포함한 최신 전체 사용 순서는 [0.21.9 매뉴얼](../0.21.9/README.ko.md)을 참고하세요. [0.21.8 고정 태그의 README](https://github.com/jhoon-dev/PMCanvas/blob/web-v0.21.8/web/README.md)에서 당시 운영 안내를 확인할 수 있습니다.
