# PM Canvas 데스크톱 1.9.1

1.9.1은 Windows Store 인증 반려 사유를 수정한 재제출 버전입니다. 실제 심사·게시 상태는 [Windows 배포 기록](../../../../desktop/WINDOWS-STORE.md)에서 확인합니다.

기능별 사용법은 [1.9.0 사용 매뉴얼](../1.9.0/README.ko.md)을 따릅니다. 전용 P·일정 막대 아이콘으로 바뀌며, 업무·완료 기록·계층·기준 계획의 파일 형식은 바뀌지 않습니다.

## 기존 데이터 전환

1. 기존 EXE 앱에서 프로젝트를 파일로 저장하고 앱을 완전히 종료합니다.
2. Microsoft Store 버전을 실행합니다. 최초 실행 시 기존 EXE의 작업·설정·언어를 새 프로필에 복사하며 기존 파일은 이동하거나 삭제하지 않습니다.
3. 프로젝트·미저장 작업·언어·시간대를 확인한 뒤 Store 버전을 계속 사용합니다. 이전 EXE와 새 Store 앱은 별도 프로필이므로 전환 이후 변경은 서로 자동 동기화되지 않습니다.

Store 설정·자동 복구 위치는 `%USERPROFILE%\PM Canvas\Profile`입니다. 업데이트·앱 제거·재설치 후에도 유지됩니다. 새 프로필이 이미 있으면 EXE 데이터를 다시 복사해 덮어쓰지 않습니다. 프로젝트와 내보낸 파일은 사용자가 선택한 기존 위치에 남습니다.

기존 EXE 원본은 `%APPDATA%\pmcanvas-desktop` 또는 `%APPDATA%\PM Canvas Desktop`에 유지됩니다. 새 프로필로 복사하지 못하면 부분 복사본으로 시작하지 않으므로, 기존 앱 종료와 폴더 접근 권한을 확인한 뒤 다시 실행하세요.

앱 제거만으로 프로젝트와 프로필이 모두 삭제되지 않습니다. 전체 삭제를 원하면 앱 종료 후 위 두 종류의 프로필과 직접 저장한 파일·별도 백업을 함께 확인하세요.
