# PM Canvas 데스크톱 0.8.3 사용 안내

이 문서는 0.8.3의 기존 기능을 안내합니다. 여러 프로젝트 탭·공통 그래프·새 설정 메뉴는 [0.8.4 매뉴얼](../0.8.4/README.ko.md)을 참고하세요.

1. 파일 메뉴에서 프로젝트를 새로 만들거나 `.pmcanvas`를 엽니다.
2. 참여인력의 근무시간·투입률을 등록하고 업무·일정과 세부 작업 공수를 입력합니다.
3. WBS 계층·기준 계획과 일정 점검을 사용하고 완료 체크에서 실제 완료일을 기록합니다.
4. 보고서에서 업무 현황·기간별 완료 기록을 Excel·CSV로 저장합니다. Excel 가져오기는 양식·열 연결·오류 미리보기 후 적용합니다.
5. 프로젝트와 복구 데이터를 보존하려면 설치 폴더 밖에 저장하고 백업합니다.

Windows 공개 배포 경로는 Microsoft Store입니다. 예전 무서명 EXE는 공개 배포 대상으로 사용하지 않습니다. 0.8.3은 기본 아이콘 통일, 개인정보처리방침과 Store 패키지 빌드 번호, 계층 WBS 번호 출력을 보완했습니다. [변경 이력](../../../../desktop/CHANGELOG.md)
