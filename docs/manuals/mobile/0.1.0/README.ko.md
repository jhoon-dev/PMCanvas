# PM Canvas 모바일 0.1.0 사용 안내

처음 제공한 오프라인 모바일 버전입니다. 프로젝트·참여인력·업무·세부 작업을 등록하고 완료 체크로 진척률을 기록합니다. 변경은 기기에 자동 저장하며 더보기에서 실행 취소·다시 실행과 프로젝트·CSV 공유를 사용합니다. 프로젝트 가져오기는 새 사본을 만듭니다.

0.1.0에는 계층 이동·기준 계획 작성·Excel 입출력과 독립된 관리 화면이 포함되지 않았습니다. 이 기능은 [0.2.0 매뉴얼](../0.2.0/README.ko.md)을 참고하세요. 이전 설치본의 배포·실기기 검증 기록은 [모바일 README](../../../../mobile/README.md)에 보존합니다.
