버전 번호는 각 제품의 앱 버전입니다. Windows 앱 표시 버전과 Store 패키지의 앞 세 숫자는 같습니다. 예를 들어 앱 1.9.0은 Windows 패키지 MSIX **1.9.0.0**으로 제출합니다. 마지막 0은 Store가 요구하는 예약 필드입니다. Windows 1.9.0는 이번 Store 제출 대상이며, 심사·게시 상태는 [Windows 배포 기록](../../desktop/WINDOWS-STORE.md)에서 확인합니다. 모바일의 실제 배포 상태는 해당 버전 매뉴얼의 배포 안내를 확인합니다.

화면은 **스마트워크 통합 플랫폼 구축** 프로젝트의 가상 데이터로 촬영했습니다. 인력 18명, WBS 186개(일반 업무 144개·요약 30개·마일스톤 12개), 세부 작업 864개, 이슈·리스크 36개, 투입 계획 54개, 발행 주간보고 6개를 사용합니다. 버전 폴더의 이미지는 해당 버전 화면과 함께 보존합니다.

공통 기능은 프로젝트·인력·WBS·일정·진척 그래프·마일스톤·투입 계획·이슈/리스크·주간보고·Excel/CSV입니다. 로그인·팀 공유·서버 관리는 웹에서 제공합니다.

가상 예제 생성과 현재 버전 화면 재촬영은 [매뉴얼 도구 안내](../../scripts/manuals/README.md)를 참고하세요. 도구 소스는 버전 관리하고 생성물은 검토 후 해당 버전 문서에 반영합니다.
