# PM Canvas 새 ID 심사 영상·테스트 안내

준비일: 2026-11-02 (한국 시간). Bundle ID **app.toolmoa.pmcanvas**, Apple ID **6829387538**. 이전 iOS 앱의 Guideline 2.1 요청을 반영한 안내입니다. 실제 테스트 결과·영상은 아직 대기 중입니다.

## 설치할 TestFlight 빌드

| 기기        | 앱 버전 (빌드)      | 내부 그룹                              |
| ----------- | ------------------- | -------------------------------------- |
| iPhone·iPad | **0.1.0 (20.1)**    | PM Canvas Release QA                   |
| Mac         | 현재 데스크톱 1.9.0 | 현재 버전 TestFlight 빌드 준비 후 검증 |

초대받은 개발자 Apple 계정으로 각 기기의 TestFlight에서 초대를 수락하고 PM Canvas를 설치합니다. iPhone·iPad는 같은 iOS 빌드입니다. TestFlight의 앱 상세 화면에서 실제 버전·빌드 번호를 확인하세요. 다른 빌드가 표시되면 먼저 알려주세요. 새 ID의 앱은 이전 앱과 별개이므로, 이전 앱을 삭제하지 않고 기존 프로젝트가 필요할 때만 파일로 내보내 가져옵니다.

기기는 최신 호환 정식 OS로 업데이트하고, 모델·정확한 OS 버전·빌드 번호·테스트 날짜를 [결과표](physical-device-results.csv)에 적습니다. 개인 프로젝트 대신 아래 가상 자료를 사용하고 알림이 영상에 들어오지 않도록 정리합니다. 계정·전화번호가 보이는 설정 화면은 영상에 넣을 필요가 없습니다.

## iPhone 영상 순서

권장 길이는 3~5분이며 Apple이 정한 길이 제한은 아닙니다. 실물 기기에서 화면 기록을 켜고 홈 화면으로 나온 다음 **PM Canvas 실행부터** 연속으로 보여주세요. 음성 설명은 필수가 아닙니다.

| 순서 | 조작                                                                         | 보여줄 결과                                          |
| ---- | ---------------------------------------------------------------------------- | ---------------------------------------------------- |
| 1    | 제어 센터에서 화면 기록 시작 → 홈 화면 → PM Canvas 실행                      | 시작 화면과 프로젝트 목록                            |
| 2    | 목록의 개인정보처리방침을 열었다 닫기 → 새 프로젝트 `심사 데모` 생성·저장    | 로그인 없이 시작 가능                                |
| 3    | 더보기 → 참여인력 → 추가 → `Alex` 저장                                       | 참여인력 등록                                        |
| 4    | 업무 → 업무 추가 → `자료 준비` 입력·저장. 같은 방법으로 `최종 검토` 추가     | 세부 작업을 비우면 업무명이 체크 항목, 각 기본 4시간 |
| 5    | 첫 업무 편집 → `담당자 · 일정` 펼치기 → Alex 지정·날짜 확인 → 저장           | 입력·키보드·저장 동작                                |
| 6    | 완료 체크에서 오늘 날짜로 첫 항목 완료 → 현황                                | 같은 공수의 두 업무 중 하나 완료: **50%**            |
| 7    | 완료 체크에서 완료 취소 또는 즉시 되돌리기 → 다시 완료                       | 변경·되돌리기 후 최종 50% 유지                       |
| 8    | 더보기 → 프로젝트 내보내기 → 공유 시트 → 파일에 저장. 업무 보고서 CSV도 저장 | iOS 공유·파일 기능                                   |
| 9    | 프로젝트 가져오기에서 방금 내보낸 프로젝트 선택                              | 원본을 덮어쓰지 않고 별도 사본 생성                  |
| 10   | 홈 화면 → 앱 전환기에서 앱 종료 → 다시 실행 → 원래 `심사 데모` 열기          | 업무 2개·완료 기록·50% 복원                          |

화면 기록은 사진 앱에 저장됩니다. 완료한 영상을 재생해 시작 장면·저장·가져오기·재실행이 빠짐없이 보이는지 확인합니다. 실패하면 그대로 결과표에 기록하고, 정상 동작한 것처럼 편집하지 않습니다.

## iPad 영상·테스트

실물 iPad에서도 위 주요 흐름을 반복합니다. 이전 Apple 메시지는 지원 플랫폼의 실물 QA와 실물 기기 녹화를 요청했으며, **두 개의 별도 전체 영상을 명시하지는 않았습니다**. 지원 범위를 분명히 보여주기 위해 iPhone·iPad 각각 촬영하는 방식을 권합니다. iPad가 없으면 iPhone 자료부터 준비하고 iPad 결과는 미완료로 남겨주세요. 시뮬레이터 영상을 실물 영상으로 제출하지 않습니다.

## Mac 영상 순서

Mac은 실물 Mac의 TestFlight 설치본으로 촬영합니다. 기존 iOS 요청을 선제적으로 보완하는 자료이며, 별도 Mac 영상 요청이 확인된 것은 아닙니다. 권장 길이는 4~6분입니다. 앱을 닫은 바탕화면에서 **Shift + Command + 5**로 화면 기록을 시작합니다. 파일·폴더 선택 창도 보이도록 전체 화면을 녹화하세요.

| 순서 | 조작                                                                        | 보여줄 결과                                                      |
| ---- | --------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| 1    | 바탕화면 → PM Canvas 실행 → 새 프로젝트 `Mac 심사 데모` 생성                | 앱 시작·계정 없는 사용                                           |
| 2    | 참여인력 Alex 추가 → 업무 2개 생성                                          | `자료 준비`, `최종 검토`; 각 세부 작업 1개·**1시간** 입력        |
| 3    | 완료 체크에서 오늘 날짜로 첫 항목 완료 → 현황                               | **50%** 진척률                                                   |
| 4    | 첫 업무 이름 편집 → 실행 취소 → 다시 실행                                   | 변경과 복원                                                      |
| 5    | 별도 `PMCanvas Review` 폴더를 만들고 `.pmcanvas` 저장                       | 추가 폴더 권한 창에서는 **파일이 들어갈 바로 그 상위 폴더** 선택 |
| 6    | 앱 정상 종료 → 다시 실행 → 저장 파일 열기                                   | 업무·완료 기록 유지, 저장 폴더 접근 복원                         |
| 7    | 다른 이름으로 저장해 별도 사본 생성                                         | 원본을 보존하는 저장                                             |
| 8    | 보고서에서 Excel·CSV 저장 → 파일 옵션의 웹 JSON 내보내기·가져오기           | 로컬 파일 입출력                                                 |
| 9    | 파일 옵션 → Excel 입력 양식 저장 → 그 양식 가져오기 → 미리보기 확인 후 적용 | Excel 파일 처리; Excel 앱 설치 불필요                            |
| 10   | 개인정보처리방침 열기 → 녹화 종료                                           | 지원·개인정보 안내 접근                                          |

첫 저장의 폴더 권한은 안전한 파일 교체 저장과 재실행 후 접근을 위한 기능입니다. 별도 테스트에서는 권한 취소·잘못된 폴더 선택 시 저장되지 않는지도 확인합니다. 이 검증에 실제 작업 파일을 사용하지 않습니다.

## 영상 외에 확인할 항목

- iOS·iPadOS: 작은 화면 키보드·스크롤, 미저장 입력 닫기 보호, 세로·가로 중 지원 방향, 오프라인 편집, 백그라운드 복귀, 강제 종료 후 복원, 파일 선택기·공유 시트.
- macOS: 폴더 선택 취소·다른 폴더 거부, 첫 저장·다른 이름 저장·재실행, 미저장 복구, 외부 파일 변경 보호, Excel 가져오기·내보내기, WBS·기준 계획, 한국어·영어, Mac App Store 업데이트 화면 이동. Intel/Apple Silicon 중 실제 테스트한 칩만 기록합니다.
- 실패가 있으면 재현 순서와 실제 메시지를 남깁니다. 앱 수정으로 새 빌드를 올릴 경우 새 빌드로 다시 테스트·촬영합니다.

## 전달할 결과와 메모 마무리

영상 파일은 `PMCanvas-iPhone-0.1.0-20.1-YYYYMMDD.mov`, `PMCanvas-iPad-0.1.0-20.1-YYYYMMDD.mov`, `PMCanvas-Mac-1.9.0-BUILD-YYYYMMDD.mov`처럼 구분합니다. 기기가 만든 원본 확장자 `.mp4`도 유지해도 됩니다. 결과표에 실제 기기·OS·날짜·성공/실패·영상 파일명을 적습니다.

[iOS 영문 심사 메모](ios-review-notes.txt)는 이전 iOS 요청 1~6번에 대응합니다. Mac은 현재 버전의 실제 검증 결과로 새 심사 메모를 작성합니다. 현재 1번의 `[PENDING]`은 실제 결과·영상 링크로 교체해야 합니다. 실제 테스트를 마친 뒤 준비 중 문구를 제거하고, 제출 빌드와 영상 빌드가 같은지 확인합니다. 메모는 각각 4,000자 이내로 유지합니다.

Apple 심사 첨부가 영상 형식·크기를 지원하면 첨부하고, 그렇지 않으면 로그인이나 접근 승인 없이 심사자가 재생할 수 있는 링크를 제공합니다. 링크 재생을 확인한 다음 메모에 넣습니다. 현재 심사 제출 단계는 실물 QA·영상 확보 후입니다.
