PM Canvas iOS 0.1.0 (20.1) / app.toolmoa.pmcanvas
실물 iPhone·iPad에서 테스트합니다. 이전 dev.jhoon.pmcanvas 앱과 별도 앱입니다. 기존 앱을 삭제하지 마세요. 필요한 프로젝트는 기존 앱에서 내보내 새 앱에 가져옵니다.

1. 새 프로젝트 만들기 → 더보기 > 참여인력에 Alex 추가.
2. 업무명만으로 업무 2개 만들기. 각각 기본 4시간이며 세부 작업을 비우면 업무명이 체크 항목이 됩니다.
3. 담당자 · 일정을 펼쳐 편집하고 저장. 작은 화면의 키보드·스크롤·저장/취소 버튼 확인.
4. 완료 체크에서 오늘 날짜로 업무 1개 완료 → 현황 50% 확인 → 체크 해제/즉시 되돌리기 확인.
5. 앱 종료·재실행 후 프로젝트와 완료 기록 유지 확인.
6. 더보기 > 프로젝트 내보내기 / 업무 보고서 CSV → 공유 시트 > 파일에 저장. 프로젝트 가져오기로 새 사본 생성 확인.
7. 오프라인 편집, 백그라운드 복귀, 미저장 입력 닫기 보호, 개인정보처리방침 확인.

영상은 실물 기기 홈 화면에서 녹화를 시작하고 앱 실행부터 보여주세요. 기기 모델·정확한 OS·빌드 번호·테스트 날짜와 실패 증상도 기록합니다. 촬영 안내의 순서와 결과표를 사용해 주세요.
