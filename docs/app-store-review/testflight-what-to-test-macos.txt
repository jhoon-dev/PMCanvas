PM Canvas macOS 0.8.3 (60) / app.toolmoa.pmcanvas
Mac의 TestFlight에서 설치한 앱으로 확인합니다. 배포용 PKG를 직접 실행해 검증하지 않습니다. 기존 앱·실제 프로젝트는 보존하고 전용 테스트 폴더를 사용합니다.

1. 실행 → 새 프로젝트 → 참여인력 Alex → 업무 2개(각 세부 작업 1개, 각 1시간).
2. 오늘 날짜로 첫 항목 완료 → 현황 50% 확인. 편집·실행 취소·다시 실행 확인.
3. 전용 폴더에 .pmcanvas 저장. 추가 권한 창에서 저장 파일의 상위 폴더를 선택. 취소/다른 폴더 선택 시 저장되지 않는지 별도 확인.
4. 정상 종료·재실행 → 저장 파일 열기 → 내용/완료 기록과 폴더 접근 유지 확인. 다른 이름 저장도 확인.
5. 보고서 Excel/CSV, 웹 JSON 내보내기/가져오기 확인. 앱이 생성한 Excel 입력 양식으로 미리보기 후 가져오기 확인.
6. WBS·기준 계획, 한국어/영어, 개인정보처리방침, Mac App Store 업데이트 이동 확인.

영상은 앱이 닫힌 바탕화면에서 녹화를 시작해 앱 실행부터 보여주세요. Mac 모델·칩·정확한 macOS·앱 빌드·날짜와 실패 증상을 기록합니다. 촬영 안내와 결과표를 사용해 주세요.
