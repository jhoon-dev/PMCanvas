# PM Canvas iOS 심사 준비

앱은 **app.toolmoa.pmcanvas / Apple ID 6829387538**입니다. 이 문서는 iOS 심사 준비 자료입니다. iPhone·iPad의 **0.1.0 (20.1)** 빌드와 심사 메모는 기존 확인 기록을 기준으로 하며, 실물 기기 정보·QA 결과·영상 링크는 `[PENDING]`입니다.

데스크톱은 [현재 1.9.0 매뉴얼](../manuals/desktop/1.9.0/README.ko.md)과 [Mac App Store 절차](../../desktop/MAC-APP-STORE.md)를 사용합니다.

## 사용할 자료

- [기기별 설치·촬영 순서](recording-guide.ko.md)
- [iOS 영문 심사 메모](ios-review-notes.txt)
- [iOS TestFlight 테스트 내용](testflight-what-to-test-ios.txt)
- [실물 기기 결과표](physical-device-results.csv): 실제로 확인하기 전에는 `NOT_TESTED`를 유지합니다.

## 촬영 후 제출 전

1. 실제 기기 모델·정확한 OS·테스트 날짜·빌드 번호와 단계별 성공/실패를 결과표에 기록합니다.
2. 영상이 앱 실행부터 주요 흐름까지 포함하는지 확인하고 재생 가능한 첨부 또는 심사자 접근 가능 링크를 준비합니다.
3. 메모 1번에 실제 결과·영상 링크를 넣고 준비 중 문구를 제거합니다. 메모 길이는 다시 확인합니다.
4. 제출할 빌드와 테스트·영상 빌드가 같은지 확인합니다. 실패 수정으로 빌드가 바뀌면 해당 빌드를 다시 검증합니다.
5. 실물 QA와 영상 확보 후 App Review에 제출합니다. iOS는 **제출 준비 중**입니다.

[iOS 서명·Apple 검증·업로드 기록](https://github.com/jhoon-dev/PMCanvas/actions/runs/41296552107)을 참고합니다.
