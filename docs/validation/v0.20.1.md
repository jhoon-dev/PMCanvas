# 검증 결과 · 2026-10-26 · 0.20.1

- XML 파서 0.9.12의 `onError` API로 SAML 검증을 전환했다. 정상 서명 응답·assertion·메타데이터·SP 요청·HTTP 콜백은 통과하고 서명 누락·잘못된 Recipient·요청 재사용은 거부한다. 파서 경고로 복구되는 XML, 닫히지 않은 태그, 미정의 엔티티, DTD/엔티티 선언과 잘못된 assertion도 거부하는 회귀 검증을 추가했다.
- checkout 7.0.1, setup-node 7.1.0, upload-artifact 7.0.2와 CodeQL 업데이트를 통합했다. 모든 GitHub Actions는 전체 커밋 SHA로 고정한다.
- 공개 파일 검사는 실제 운영 설정을 읽지 않고 Git 추적/추가 예정 파일만 검사한다. 강제 추적한 개인 설정·키·덤프, 실제 호스트/이메일/IP/개인 홈 경로, 직접 입력한 비밀값을 거부한다. 문서 이외 소스의 개인 키·알려진 토큰도 검사하며, CI 실패 출력에는 발견한 비밀값 원문을 넣지 않는다.
- 예약 도메인·문서 IP·loopback, 빈 설정·환경 변수와 중첩 환경 변수 fallback, 공식 문서·Entra 예제의 정상 통과를 확인했다. 원본 출처 기록은 개인 경로를 제거하고 출처와 해시를 보존했다.
- 공개 ZIP의 문서 내용 검사와 개인 설정 혼입 차단, 경로 탈출·Windows 특수 파일명·중복·심볼릭 링크·암호화·손상된 체크섬·크기 초과를 검사했다. 배포 명령은 깨끗한 커밋의 공개 경로만 압축하고 ZIP 검사를 통과한 뒤 파일과 SHA-256을 출력한다. CI에 공개 파일 검사와 실제 배포 ZIP 생성 검증을 추가했다.
- 로컬에서 단위/요청 190개, 실제 HTTP·TLS SMTP 14개, 별도 PostgreSQL 19개, 실제 브라우저 5개로 총 228개가 모두 통과했다. 실패·건너뜀은 없었고 포맷·공백 검사와 npm audit도 통과했다.
- 브라우저는 회원가입 → 로컬 메일 인증 → 관리자 MFA 승인 → 업무 등록·완료 → CSV/Excel 다운로드, 동시 수정 병합, 한·영 전환·원본 데이터 보존, 모바일·키보드, 500개 업무 입력·검색·간트를 확인했다. 운영 계정·외부 메일 수신자는 테스트에 사용하지 않았다. PostgreSQL 검증용 DB는 종료 후 삭제했다.
