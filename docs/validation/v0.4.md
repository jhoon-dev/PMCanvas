# 검증 결과 · 2026-10-25 · 0.4.0

- 단위 및 요청 처리 테스트: 40개 통과(설치 설정 검증 2개 포함).
- 실제 HTTP 통신 테스트: 7개 통과. 저장 어댑터는 메모리입니다.
- PostgreSQL 18 통합 테스트: 1개 통과. 마이그레이션 재실행, FK, 롤백, 동시 수정 충돌, 권한, 완료 취소 이력을 검사했습니다.
- npm 설치, lockfile 생성, Docker 이미지 빌드 및 Compose 기동 성공. 앱과 DB 모두 healthy입니다.
- 기본 및 외부 DB Compose 설정 검사 통과. 외부 DB에는 실제 연결하지 않았습니다.
- Docker 앱 HTTP + PostgreSQL에서 최초 관리자 로그인, 프로젝트 목록 조회, 로그아웃 성공.
- setup 재실행 시 기존 .env 덮어쓰기 거절 확인.
- pg_dump 백업 및 새 DB 복원 성공. 복원된 관리자 계정 수 1 확인. 검증용 DB 두 개는 확인 후 삭제했습니다.
- 브라우저 로그인 화면 확인. 초기 auth/me 401은 로그인 전 세션 확인입니다. 로그인 후 전체 UI·모바일 흐름은 이번에 검증하지 않았습니다.
- 로컬 주소 http://localhost:4180/pmcanvas/ . 관리자 admin@pmcanvas.local, 비밀번호는 .env의 ADMIN_PASSWORD에 보관합니다.
- 운영 서버 접속·도메인 설정·외부 배포는 수행하지 않았습니다.

복원 명령은 기존 DB를 덮어쓰지 않고 새 DB만 생성합니다. 복원 확인 후 .env의 APP_DATABASE를 바꾸고 다시 기동하면 전환합니다. 외부 DB의 실제 TLS 연결·백업·복원은 해당 환경에서 추가 검증이 필요합니다.
