- 변경 전후 빈 프로젝트·일반 프로젝트·과거 조회·조회자/미지정 담당자·HTML 삽입 입력에 대해 전체 업무/내 업무·담당자·상태·검색·미완료 필터 조합 20개를 실행했다. 업무 체크·인력 HTML 총 40개의 SHA-256이 변경 전후 동일했다.
- 회귀 테스트 9개를 추가했다. 인증 링크의 종류/형식·URL 토큰 제거·미저장/저장 중 화면 이동 금지·로컬/AD 로그인 요청·미저장 계정 전환 차단·필터·과거 완료 기록·HTML 이스케이프·체크/취소·실패 안내·인력 입력 검증과 기록 보존을 확인했다.
- 기존 단위·요청 테스트 157개 실행과 추가 회귀 테스트 실행을 통과했다. 최종 단위·요청 테스트 수는 158개이며, 실제 HTTP·TLS SMTP 13개·별도 PostgreSQL 18개도 통과했다. 포맷 검사와 git diff 공백 검사를 통과했다. 새 브라우저 모듈을 정적 파일 허용 목록과 하위 경로 HTTP 테스트에 함께 등록했다.
- 실제 브라우저: 이메일 가입 신청 → 로컬 TLS SMTP의 인증 링크 → 이름·비밀번호 설정 → 관리자 MFA 등록/로그인 → 프로젝트 초대와 가입 승인 → 비밀번호 찾기 메일 → 새 비밀번호 설정 → 새 비밀번호 로그인 → 업무 등록/저장 → 담당자·검색 필터 → 완료 체크/취소 → 미완료만 보기 → 인력 진척 100% 반영을 확인했다.
- 인력 추가 및 이름/투입률 수정 후 하루 6시간·투입률 75%의 가용시간 4.5시간을 확인했다. 담당 업무 1개·완료 공수 8/8h·진척 100%가 새로고침 후에도 유지됐다. 최종 브라우저 오류 로그는 없었다.
- 테스트는 일회용 메모리 저장소·loopback SMTP·별도 테스트 DB에서 진행했다. 운영 계정·SMTP·DB 스키마·계산 규칙은 변경하지 않았다.
