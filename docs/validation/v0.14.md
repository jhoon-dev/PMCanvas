# 검증 결과 · 2026-10-26 · 0.14.0

- 단위·요청 처리 109개, 실제 HTTP·TLS SMTP 11개, 실제 PostgreSQL 9개: 합계 129개 검증.
- 관리자 SMTP 설정 저장·읽기·테스트 발송 API의 일반 사용자 접근·CSRF·Origin 차단, 반복 발송 제한과 고정 본문·단일 수신자 검증.
- DB/API/감사 로그에 비밀번호 원문 미노출, 암호화 보관·빈칸 유지·서버/계정 변경 시 재입력·인증 해제 시 삭제·손상된 암호문 교체 확인.
- 별도 PostgreSQL DB에서 008 마이그레이션 반복 적용, 다른 저장 어댑터 인스턴스와 재시작 후 암호 복구, 동시 수정 한 번 성공·늦은 저장 409 충돌 확인. 테스트 DB와 임시 파일 정리 완료.
- 실제 TLS SMTP로 관리자 테스트 메일 수신 후 새 설정을 비밀번호 재설정 발송에 즉시 사용. 발송 중지 상태가 공개 로그인 정책에 바로 반영됨을 확인.
- 브라우저에서 테스트용 관리자 MFA 로그인 → 설정 입력 → 저장 → 테스트 수신 → 잘못된 비밀번호의 인증 실패 → 수정 후 수신 성공 확인. 화면 재진입 시 비밀번호 입력칸은 비어 있고 등록 상태만 표시.
- 일반 사용자에게 설정 메뉴 미표시·API 403, 390px 모바일 한 열 배치·가로 넘침 없음·스크롤 중 닫기 버튼 유지 확인.
- 실제 외부 수신자·운영 SMTP에 테스트 메일을 보내지 않았고 운영 관리자 MFA를 대신 등록하지 않음. 기존 파일 설정은 보존.
- 업데이트 전 운영 DB 백업 후 008 마이그레이션·앱/DB healthcheck 정상. 실제 서비스의 익명 관리자 설정 접근 401과 기존 발송 비활성 상태 유지 확인. npm audit 취약점 0개.
