# 검증 결과 · 2026-10-25 · 0.8.0

- npm test: 73개 통과. Excel 시트 구성, 필터 선택 업무, 날짜/숫자/진척률 형식, 수식 문자열 안전성, 장기 간트 120칸 제한을 검증했습니다.
- Excel API: 인증, CSRF, 프로젝트 접근 권한, 잘못된 날짜/선택 거절, XLSX 응답 헤더, 출력 후 revision 보존을 검증했습니다.
- 실제 HTTP 통신 테스트: 7개 통과. 이번 실행 합계 80개입니다.
- 브라우저: WBS 업무명을 저장 전 초안으로 수정한 후 Excel 출력 버튼으로 .xlsx 다운로드 성공, 초안 상태 유지 확인.
- npm audit --omit=dev: 취약점 0개. ExcelJS의 uuid 의존성은 CJS 호환 보안 수정 버전 11.1.1로 고정했습니다.
- 업데이트 전 DB 백업, Docker 빌드/기동 및 앱/DB healthcheck 정상 확인. DB 스키마 변경 없음.
- PostgreSQL 통합 테스트 4개와 기존 WBS 편집 UI 검증은 0.7.0 검증 기록(v0.7.md)을 참고하세요. 이번 Excel 변경에서는 재실행하지 않았습니다.
