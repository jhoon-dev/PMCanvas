## 회귀 범위

하위 경로의 config·secrets·인증서가 ZIP에서 차단되고, 허용된 예제에도 내용 검사가 적용되는지 확인했습니다. 실제 비공개 설정은 검사하거나 배포본에 넣지 않습니다.

브라우저 시간을 자정 전후로 이동해 편집 중 입력 보존·편집 종료 후 오늘 전환·과거 조회일 유지를 확인했습니다. 기존 가입·메일 인증·MFA 승인·업무 등록과 완료·Excel·동시 수정·영어·모바일·500개 업무 시나리오도 통과했습니다.

프로젝트 10개·100개의 모의 DB 검증에서 기존 목록·내 업무 API는 각각 SELECT 4회로 고정되고, 변경 없는 동기화는 1회입니다. 실제 PostgreSQL에서는 중복 업무 ID가 있는 두 프로젝트의 데이터 격리, 선택 상세와 담당 업무만 반환, 역할 변경·계정 연결·접근 회수 반영과 무변경 조회 1회를 확인했습니다. SELECT 횟수에는 트랜잭션 시작·종료 명령을 포함하지 않습니다.

실제 복구 검증은 테스트용 원본 DB를 pg_dump하고 새 DB에 pg_restore한 후 운영 복원 명령과 같은 인증 정리 SQL을 적용했습니다. 이전 세션·MFA 요청·복구 코드의 거절, 비밀번호 로그인과 기존 TOTP 인증, 암호화된 SMTP 비밀번호를 사용한 로컬 TLS 메일 수신, 완료 기록과 조회자 권한을 확인했습니다. 잘못된 키로 SMTP 비밀값을 복호화할 수 없는지도 검증했습니다. 테스트가 만든 DB·덤프만 정리했습니다.

이 앱 복구 검증은 CI의 테스트 데이터로 실행합니다. 운영 자동 백업의 스키마·참조 검사와 별개이며, 실제 계정 로그인이나 외부 메일 발송은 수행하지 않습니다.
